# VARENA — Full-stack prototype

## Run locally
1. Install Node.js 18+.
2. In this folder run `npm install`.
3. Run `npm start`.
4. Open http://localhost:3000

## What works
- Responsive luxury frontend
- External image links
- Room catalogue loaded from backend
- Booking request API + JSON database
- Maison shopping bag + order request API
- Membership request API
- Scroll animations and modals
- Mobile layout

## Important
All VARENA prices, rooms, products and business claims are fictional prototype data. They are not live hotel availability or real products.

The image URLs use Unsplash-hosted images for the prototype. For a real commercial launch, replace them with owned/licensed photography and keep a proper image attribution/licensing record. Unsplash's current license generally permits free commercial use, while its API has additional hotlinking/attribution guidelines.
